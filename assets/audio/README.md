# 🔊 الأصوات المطلوبة (Audio Assets)

اللعبة تشتغل بدون الأصوات (الـ AudioManager بيتعامل مع الملفات المفقودة بدون كراش)، لكن لمتعة كاملة لازم تنزل الأصوات.

## خطوات التحميل (10 دقائق)

١. روح [pixabay.com/sound-effects](https://pixabay.com/sound-effects) — مجاني ١٠٠٪، استخدام تجاري.

٢. حمّل الأصوات دي بنفس الأسماء **بالضبط** (mp3 أو wav):

### music/ (Background)

| الملف | كلمات بحث |
|---|---|
| `bg_music.mp3` | "middle eastern oud calm loop" |

## نصايح
- اختبر على سماعة وعلى السماعة الخارجية للموبايل.
- خلي كل الـ sfx أقل من ثانية لو ممكن — الأصوات الطويلة بتقطع تجربة اللعب.
- الـ bg_music لازم يكون loop seamless (أول وآخر ثانية متشابهين).
